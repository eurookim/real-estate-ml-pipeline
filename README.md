# Real Estate ML Pipeline

## Overview
End-to-end explanatory data analysis pipeline built on 
400,000+ rows of real estate data during a Data Science internship 
at IDX Exchange.

## Methods
- Exploratory data analysis (EDA)
- Random Forest imputation for missing values
- LASSO (L1) regression with cross-validated alpha tuning
- Feature dimensionality reduction

## Tech Stack
Python · Pandas · Scikit-learn · SciPy · Matplotlib
